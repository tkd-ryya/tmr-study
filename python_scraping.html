【BeautifulSoup】

  1. スクレイピングの基本の流れ

    2. (1)RequestsでHTMLを取得する。

    (2)取得したHTMLを解析する。（BeautifulSoup）

    (3)自分が欲しい情報を取得する。


  2. 文法
    • タグを取得するとき：soup.find()
    • すべてのタグを取得するとき：soup.find_all() ➡ リストで取得されるので、soup.find_all("h2")[0]などの形で取得できる。
    • テキストを取得するとき：soup.fond().text

  3. コード例_01（基本形）
    4. import requests
from bs4 import BeautifulSoup

url="https://www.python.org/"
res = requests.get(url)

if res.status.code==200:
    soup = BeautifulSoup(res.text ,"html.parser")
    print(soup.find("h2").text)
else:
    raise
    print("アクセスに失敗しました。")
  4. コード例_02（h2タグの中身をすべて取出したいとき）
    5. for i,h2_tag in enumerate(soup.find_all("h2")):
    print(i,h2_tag.text)
  5. コード例_03（find_all()で取得したh2からテキストだけ取得して、h2_text_listに格納したいとき）
    6. h2_text_list=[]

for i,h2_tag in enumerate(soup.find_all("h2")):
    h2_text_list.append(h2_tag.text)
  6. コード例_04（xxxクラスとyyyクラスを持つspanタグをすべて取得する。）
    7. soup.find_all("span",class_=["xxx","yyy"])

with sync_playwright() as p:

    browser = p.chromium.launch(headless=False) # Chromeを起動
    page = browser.new_page() # 新しいページを作成
    page.goto("https://demo.playwright.dev/todomvc/") # webページを開く


    # ===============================
    #  JavaScript実行後のHTMLを取得
    # ===============================
    html = page.content()
    print(html)

    page.wait_for_timeout(3000) # ブラウザが閉じないように待機。単位は「msec」


    # 「.new-todo」を見つける方法 → 入力欄で右クリック→検証
    # 「input class="new-todo" ...」のような内容が確認できる。
    # classなら「.xxx」、idなら「#xxx」
    page.locator(".new-todo").fill("Pythonの勉強")
    page.wait_for_timeout(2000)
    page.locator(".new-todo").press("Enter")
    page.wait_for_timeout(2000)

    browser.close()
