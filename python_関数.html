  1. 規格値で判定し、dfに判定列を追加する。
  1. 基本形は「def 関数名():」

    2. 規格値で判定して、判定列を作成する。

    
import pandas as pd
df =pd.DataFrame({"Voffset":[-12,-7,5,9,13]})
print(df)

def judge_Voffset( Voffset ):
    if -10 <= Voffset <= 10:
        return "OK"
    else:
        return "NG"

df["判定"] = df["Voffset"].apply(judge_Voffset)
print(df)
